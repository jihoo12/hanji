익숙한 마크다운은 그대로 쓰면 됩니다. 이 페이지는 한지가 **더한 것**을 중심으로 설명합니다.

## 기본 문법

**굵게**, *기울임*, ~~취소선~~, ==형광펜==, `코드`, [링크](01-start.md), 그리고 https://example.com 같은 주소는 자동으로 링크가 됩니다.

> 인용문은 이렇게 보입니다.

- 목록
  - 중첩 목록
- [x] 끝낸 일
- [ ] 남은 일

| 왼쪽 | 가운데 | 오른쪽 |
| :--- | :---: | ---: |
| 표도 | 됩니다 | 1,000 |

다른 페이지로 가는 링크는 **파일 경로 그대로** 쓰면 됩니다. `[시작하기](01-start.md)` 라고 쓰면
한지가 실제 주소(`/docs/start/`)로 바꿔 주고, 없는 파일을 가리키면 빌드할 때 알려 줍니다.

## 코드 블록

언어 이름 뒤에 제목과 강조할 줄을 적을 수 있습니다. 강조는 빌드할 때 끝나므로 브라우저에서 따로 할 일이 없습니다.

````md
```go title="main.go" {3-4}
func main() {
    // 이 아래 두 줄이 강조됩니다
    msg := "안녕, 한지"
    fmt.Println(msg)
}
```
````

```go title="main.go" {3-4}
func main() {
    // 이 아래 두 줄이 강조됩니다
    msg := "안녕, 한지"
    fmt.Println(msg)
}
```

## 디렉티브

콜론 세 개로 여닫는 블록입니다. 이름 뒤에 `키="값"` 으로 속성을 주고, 그 밖의 글자는 제목이 됩니다.

```md
::: tip 알아 두면 좋은 것
본문도 **마크다운**입니다.
:::
```

::: tip 알아 두면 좋은 것
본문도 **마크다운**입니다.
:::

::: warn
제목을 생략하면 기본 제목이 붙습니다. `note`, `tip`, `warn`, `danger` 네 가지가 있습니다.
:::

안에 또 넣을 때는 그냥 넣어도 되고, 헷갈리면 바깥쪽 콜론을 더 길게 쓰세요.

```md
:::: grid cols=2
::: card title="하나"
첫 번째 카드
:::
::: card title="둘" href="/blog/"
링크가 되는 카드
:::
::::
```

:::: grid cols=2
::: card title="하나"
첫 번째 카드
:::
::: card title="둘" href="/blog/"
링크가 되는 카드
:::
::::

본문이 없는 디렉티브는 콜론 두 개로 한 줄에 씁니다: `::postlist from="blog/*" limit=3`

내장 디렉티브 전체 목록과 직접 만드는 법은 [컴포넌트](04-components.md)에 있습니다.

## 빌드할 때 채워지는 값

중괄호 두 겹 안의 식은 **빌드할 때** 계산되어 글자로 굳습니다.

```md
이 글의 제목은 "{{ page.title }}"이고, 쓴 사람은 {{ page.author }}입니다.
이 사이트에는 글이 {{ pages("blog/*") | len }}편 있습니다.
```

이 글의 제목은 "{{ page.title }}"이고, 쓴 사람은 {{ page.author }}입니다.
이 사이트에는 글이 {{ pages("blog/*") | len }}편 있습니다.

`::: if` 와 `::: each` 로 본문을 조건부로 넣거나 되풀이할 수도 있습니다.

```md
::: each p in pages("blog/*") | limit(2)
- [{{ p.title }}]({{ p.url }})
:::
```

::: each p in pages("blog/*") | limit(2)
- [{{ p.title }}]({{ p.url }})
:::

쓸 수 있는 값과 함수는 [데이터와 표현식](06-data.md)에 정리되어 있습니다.

## HTML 섞어 쓰기

줄 첫머리에서 블록 태그로 시작하면 빈 줄을 만날 때까지 HTML 그대로 통과합니다.

```md
<div style="text-align:center">
  <strong>{{ site.title }}</strong> — 가운데 정렬
</div>
```

<div style="text-align:center">
  <strong>{{ site.title }}</strong> — 가운데 정렬
</div>

::: note 지원하지 않는 것
들여쓰기 네 칸 코드 블록(대신 ``` 을 쓰세요), `[text][ref]` 참조 링크, `===` 밑줄 제목은
지원하지 않습니다. 디렉티브 안에서 들여쓰기가 뜻밖의 코드로 바뀌는 일을 막기 위한 선택입니다.
:::

한지는 **마크다운으로 웹사이트 전체의 틀을 잡는 프레임워크**입니다. 글을 쓰면 페이지가 되고,
폴더를 만들면 메뉴가 되고, 중괄호를 쓰면 글이 살아 움직입니다.

## 세 가지 생각

### 1. 원문이 곧 프로그램

한지에서 가장 중요한 파일은 `.md` 입니다. 레이아웃과 컴포넌트는 HTML로 만들지만,
그것들을 *쓰는* 쪽은 언제나 마크다운입니다.

### 2. 살아있는 문서

상태를 머리말에 적으면 본문이 그 값에 반응합니다. 계산기, 설문, 체크리스트, 요금 계산표 같은 것을
자바스크립트 파일 없이 문서 안에 그대로 씁니다. → [살아있는 문서](03-live.md)

### 3. 쓴 만큼만 싣는다

빌드 결과는 정적 HTML입니다. 살아있는 표현을 쓰지 않은 페이지에는 런타임이 실리지 않고,
컴포넌트의 스타일과 스크립트는 그 컴포넌트를 쓴 페이지에만 들어갑니다.

## 한눈에 보기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 새 페이지 | `pages/` 에 `.md` 파일을 만든다 |
| 사이드바 순서 | 파일 이름 앞에 `01-`, `02-` 를 붙인다 |
| 강조 상자 | `::: tip` … `:::` |
| 값 보여주기 | `{count}` |
| 버튼 | `[누르기](@count += 1)` |
| 입력 | `[? name]` |
| 글 목록 | `::postlist from="blog/*"` |
| 내 컴포넌트 | `components/이름.html` 을 만들고 `::: 이름` |

::: tip 이 사이트가 곧 예제입니다
지금 보고 있는 문서는 `hanji new` 가 만들어 준 스타터 그대로입니다. `pages/docs/` 의 원문을
열어 놓고 읽으면 가장 빨리 배울 수 있습니다.
:::

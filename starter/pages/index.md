## 지금 이 문단이 앱입니다

아래는 그림이 아니라 이 페이지의 마크다운 원문 세 줄이 만든 결과입니다.

:::: grid cols=2
::: card title="눌러 보세요"

[하나 더](@count += 1) [처음으로](@count = 0)
:::
::: card title="적어 보세요"

## 틀은 한지가 잡습니다

파일을 놓으면 길이 되고, 폴더를 만들면 메뉴가 됩니다.

:::: grid cols=3
::: card title="파일이 곧 주소" icon="🗂️"
`pages/docs/start.md` 는 `/docs/start/` 가 됩니다. 폴더는 사이드바가, 제목은 목차가 됩니다.
:::
::: card title="살아있는 마크다운" icon="🪄"
`{값}`, `[버튼](@동작)`, `[? 입력]`. 상태가 없는 페이지에는 스크립트가 한 줄도 실리지 않습니다.
:::
::: card title="디렉티브 컴포넌트" icon="🧩"
`::: card` 처럼 쓰는 블록은 `components/card.html` 한 파일입니다. 직접 만들어 쓰세요.
:::
::: card title="기본으로 갖춘 틀" icon="🏛️"
검색, 다크 모드, 목차, 이전/다음, RSS, 사이트맵, 코드 강조까지 설정 없이 들어 있습니다.
:::
::: card title="즉시 이동" icon="⚡"
링크에 마우스를 올리면 미리 받아 두고, 누르면 화면 전환 효과와 함께 바로 바뀝니다.
:::
::: card title="단일 바이너리" icon="📦"
Go로 쓴 컴파일러 하나가 전부입니다. `node_modules` 도, 번들러 설정도 없습니다.
:::
::::
